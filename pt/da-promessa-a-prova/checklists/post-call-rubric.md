# Rubrica pós-call

Pontue toda call de descoberta ou de vendas em até uma hora. Use com transcrições (`references/ai-in-sales.md`) ou de memória. 0 / 1 / 2 por linha.

| # | Critério | 0 | 1 | 2 | Nota |
|---|---|---|---|---|---|
| 1 | **Proporção de fala** (parte do vendedor) | >60% | 45–60% | ≤45% | |
| 2 | **Perguntas feitas** (contagem) | <6 | 6–10 | 11+ | |
| 3 | **Mix de perguntas** (tipos SPIN presentes) | 1 tipo | 2–3 tipos | os 4, incl. ≥2 de Implicação | |
| 4 | **Dor captada nas palavras dele** com um número | nenhuma | só palavras | palavras + número | |
| 5 | **Custo da inação** exposto | não | implícito | declarado pelo comprador | |
| 6 | **Processo de decisão** perguntado | não | parcial | etapas, pessoas, datas | |
| 7 | **Alternativas** perguntadas (incl. status quo / interno) | não | uma | todas | |
| 8 | **Objeções** surgidas e nomeadas | ignoradas | respondidas por reflexo | diagnosticadas antes de responder | |
| 9 | **Quem mais** deveria participar, perguntado | não | sim | sim + apresentação combinada | |
| 10 | **Próximo passo** | nenhum | vago | data, participantes, propósito | |
| 11 | **E-mail de recapitulação** enviado em até 24 h com as palavras dele, números, próximo passo | não | tardio/genérico | sim | |
| 12 | **Timing do pitch** | fez pitch antes da dor | fez pitch depois de alguma dor | fez pitch depois de construir a lacuna, ou não fez | |

**Total: ___ / 24**

- 20–24: rode de novo do mesmo jeito; compartilhe como exemplo.
- 14–19: escolha as duas linhas mais baixas; uma nota de coaching para cada.
- <14: a call foi um pitch, não uma descoberta. Refaça a preparação com `templates/discovery-call-guide.md`.

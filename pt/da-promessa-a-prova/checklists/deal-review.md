# Revisão de negócio: sinais de alerta e go/no-go

Rode antes de qualquer forecast, antes de ceder em preço e semanalmente nos negócios acima do seu valor mediano.

## Sinais de alerta (qualquer um = "em risco")

- [ ] Nenhum próximo passo agendado com data.
- [ ] Nenhum contato há 14+ dias.
- [ ] Um único contato (single-threaded).
- [ ] O champion falhou duas vezes no teste "marque uma reunião com o comprador econômico".
- [ ] O comprador econômico nunca foi encontrado.
- [ ] Dor não quantificada nos números do comprador.
- [ ] Critérios de decisão não escritos por ele.
- [ ] Processo de decisão desconhecido ou "vamos ver".
- [ ] Processo burocrático (jurídico, segurança, compras) não mapeado na etapa de proposta.
- [ ] "Sim verbal" sem caminho até a assinatura.
- [ ] Desconto pedido antes da conversa de valor.
- [ ] Proposta enviada há mais de 14 dias sem resposta.
- [ ] Concorrente ou opção interna nunca discutidos.
- [ ] Capacidade de entregar não confirmada internamente.

## Go / No-go

| Pergunta | Sim | Não |
|---|---|---|
| Existe uma lacuna quantificada que o comprador declarou? | | |
| Conseguimos corrigir a causa raiz? | | |
| Já encontramos alguém que libera dinheiro? | | |
| Existe um processo de decisão com datas? | | |
| Temos ≥3 contatos engajados (ou o negócio é pequeno demais para precisar)? | | |
| Conseguimos entregar bem se eles assinarem na semana que vem? | | |

Dois ou mais "Não" → corrija antes de investir mais, ou desqualifique de forma limpa (`references/qualification.md`).

## Honestidade de etapa

| Etapa no CRM | Precisa ser verdade (critérios de etapa do SKILL.md) |
|---|---|
| Qualificado | Dor + impacto + processo nomeado |
| Descoberta concluída | Scorecard: sem vermelho em Dor, Champion e Processo |
| Proposta | Business case aceito pelo champion; EB identificado e alcançado |
| Negociação | Critérios atendidos; processo burocrático mapeado com datas |
| Commit | Caminho de assinatura confirmado pelo EB; data de kickoff proposta |

Mova os negócios *para trás* quando a evidência não existir. Um forecast é tão honesto quanto sua etapa mais fraca.

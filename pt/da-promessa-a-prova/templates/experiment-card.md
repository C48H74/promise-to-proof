Uma variável. Uma métrica. Uma regra de parada. Um responsável.

| Campo | Preencha |
|---|---|
| **Hipótese** | Se [mudarmos uma coisa], então [métrica] vai passar de [linha de base] para [meta] porque [motivo]. |
| **Gargalo que ataca** | Alcance / Qualidade dos leads / Conversão / Capacidade / Retenção (escolha um) |
| **Variável alterada** | |
| **Tudo o que fica constante** | |
| **Métrica primária** | |
| **Métrica de proteção** (não pode piorar) | |
| **Amostra necessária** | [n leads / calls / semanas] — o suficiente para ver o efeito, não uma dúzia |
| **Orçamento (dinheiro, horas)** | |
| **Responsável** | |
| **Início / data de revisão** | |
| **Continuar se** | métrica ≥ ______ e proteção OK |
| **Parar se** | métrica < ______ até a data de revisão, ou proteção violada |
| **Resultado** | |
| **Decisão** | ☐ Escalar ☐ Iterar ☐ Encerrar |
| **O que aprendemos** | |

## Regras
- A linha de base é medida antes da mudança, não lembrada.
- Não rode dois experimentos na mesma etapa do funil ao mesmo tempo.
- Registre os encerramentos; são metade do valor.

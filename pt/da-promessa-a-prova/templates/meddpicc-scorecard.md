Pontuação: **Verde** = evidência por escrito ou de duas pessoas. **Amarelo** = dito uma vez por uma pessoa. **Vermelho** = presumido ou desconhecido.

| Letra | O que sabemos (evidência, citação, fonte) | Lacuna / o que falta | Próxima ação para fechar a lacuna | Nota |
|---|---|---|---|---|
| **M** Metrics (métricas) — tamanho do problema e da solução, com unidade e período | | | | |
| **E** Economic buyer (comprador econômico) — nome; já nos reunimos com ele? | | | | |
| **D** Decision criteria (critérios de decisão) — lista escrita; quem a escreveu | | | | |
| **D** Decision process (processo de decisão) — etapas, pessoas, datas, incl. jurídico/segurança/compras | | | | |
| **P** Pain (dor) — nas palavras dele, quantificada | | | | |
| **I** Implications (implicações) — consequências que ele declarou para o negócio e para si mesmo | | | | |
| **C** Champion — nome; passou em qual teste (organograma / documento encaminhado / reunião com o EB / riscos compartilhados)? | | | | |
| **C** Competition (concorrência) — alternativas incl. status quo e interno; pontos fortes percebidos | | | | |

**Geral:** ☐ Avançar ☐ Segurar ☐ Desqualificar

**Regras**
- Qualquer vermelho em Dor, Champion ou Processo de decisão: o negócio não avança para a proposta.
- Sem contato com o comprador econômico na etapa de proposta: em risco.
- Atualize após cada contato; a data acima deve estar dentro de 14 dias, ou o negócio está estagnado.

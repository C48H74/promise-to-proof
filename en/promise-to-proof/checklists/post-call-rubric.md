# Post-call rubric

Score every discovery or sales call within an hour. Use with transcripts (`references/ai-in-sales.md`) or from memory. 0 / 1 / 2 per line.

| # | Criterion | 0 | 1 | 2 | Score |
|---|---|---|---|---|---|
| 1 | **Talk ratio** (seller share) | >60% | 45–60% | ≤45% | |
| 2 | **Questions asked** (count) | <6 | 6–10 | 11+ | |
| 3 | **Question mix** (SPIN types present) | 1 type | 2–3 types | all 4, incl. ≥2 Implication | |
| 4 | **Pain captured in their words** with a number | none | words only | words + number | |
| 5 | **Cost of inaction** surfaced | no | implied | stated by buyer | |
| 6 | **Decision process** asked | no | partial | steps, people, dates | |
| 7 | **Alternatives** asked (incl. status quo / in-house) | no | one | all | |
| 8 | **Objections** surfaced and labeled | ignored | answered reflexively | diagnosed before answering | |
| 9 | **Who else** should be involved asked | no | yes | yes + intro agreed | |
| 10 | **Next step** | none | vague | date, attendees, purpose | |
| 11 | **Recap email** sent within 24 h with their words, numbers, next step | no | late/generic | yes | |
| 12 | **Pitch timing** | pitched before pain | pitched after some pain | pitched after gap built, or not at all | |

**Total: ___ / 24**

- 20–24: run it again the same way; share as an example.
- 14–19: pick the two lowest lines; one coaching note each.
- <14: the call was a pitch, not discovery. Redo prep with `templates/discovery-call-guide.md`.

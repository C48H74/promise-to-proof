# Reading list by step

Primary sources behind the skill. Read the original before applying a framework in a high-stakes setting.

| Step / topic | Source | Why |
|---|---|---|
| Offer, pricing, value | Alex Hormozi, *$100M Offers* | Value equation, offer construction, guarantees |
| Pricing research | Van Westendorp price sensitivity method; Patrick Campbell / ProfitWell pricing writing | Acceptable price ranges from buyers |
| Metrics | David Skok, "SaaS Metrics 2.0" (forEntrepreneurs); Bessemer "State of the Cloud" | CAC, payback, LTV, NRR definitions and benchmarks |
| Qualification | Andy Whyte / MEDDPICC material; Dunkin & Dunkin, *The Qualified Sales Leader* | Qualification discipline |
| Gap Selling | Keenan, *Gap Selling* | Problem-led selling, current vs. future state |
| Discovery | Neil Rackham, *SPIN Selling* | Question types |
| Customer interviews | Rob Fitzpatrick, *The Mom Test* | Avoiding polite lies |
| Indecision | Dixon & McKenna, *The JOLT Effect* | Fixing "no decision" |
| Challenger | Dixon & Adamson, *The Challenger Sale* | Teaching and tailoring |
| Negotiation | Chris Voss, *Never Split the Difference*; Fisher & Ury, *Getting to Yes* | Labeling, calibrated questions, interests vs. positions |
| Narrative | Donald Miller, *Building a StoryBrand*; Oren Klaff, *Pitch Anything* | Clarity and frame control |
| Persuasion | Robert Cialdini, *Influence* | Reciprocity, social proof, scarcity; use ethically |
| Prospecting | Jeb Blount, *Fanatical Prospecting* | Consistent outreach |
| Cold calling | John Barrows and 30MPC (Armand Farrokh, Nick Cegelski) material | Call scripts, openers |
| Founder-led sales | Jacco van der Kooij / Winning by Design; Kazanjy, *Founding Sales* | Early sales motion |
| Outbound systems | Aaron Ross, *Predictable Revenue* | Specialized roles and pipeline |
| Referrals | John Jantsch, *Duct Tape Marketing* | Referral systems |
| Content / SEO | Andy Crestodina, *Content Chemistry* | Practical content marketing |
| AI claims | Narayanan & Kapoor, *AI Snake Oil* | Calibration about what AI can do |

## How to use
- Skim the skill reference for the step you are on; read the book only for the part you are about to apply.
- When a book contradicts a reference file, the book's evidence wins; open an issue or update the file and log it in `CHANGELOG.md`.
- Add sources you trust here with one line on why.

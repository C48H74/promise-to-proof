# Ficha de experimento

Una variable. Una métrica. Una regla de parada. Un responsable.

| Campo | Rellena |
|---|---|
| **Hipótesis** | Si [cambiamos una cosa], entonces [métrica] pasará de [línea base] a [objetivo] porque [motivo]. |
| **Cuello de botella que ataca** | Alcance / Calidad de los leads / Conversión / Capacidad / Retención (elige uno) |
| **Variable cambiada** | |
| **Todo lo que se mantiene constante** | |
| **Métrica primaria** | |
| **Métrica de protección** (no puede empeorar) | |
| **Muestra necesaria** | [n leads / llamadas / semanas] — suficiente para ver el efecto, no una docena |
| **Presupuesto (dinero, horas)** | |
| **Responsable** | |
| **Inicio / fecha de revisión** | |
| **Continuar si** | métrica ≥ ______ y protección OK |
| **Parar si** | métrica < ______ para la fecha de revisión, o protección vulnerada |
| **Resultado** | |
| **Decisión** | ☐ Escalar ☐ Iterar ☐ Terminar |
| **Qué aprendimos** | |

## Reglas
- La línea base se mide antes del cambio, no se recuerda.
- No lances dos experimentos en la misma etapa del embudo a la vez.
- Registra los cierres; son la mitad del valor.

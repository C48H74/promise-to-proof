# Revisión de negocio: señales de alerta y go/no-go

Ejecútala antes de cualquier forecast, antes de ceder en precio y semanalmente en los negocios por encima de tu valor mediano.

## Señales de alerta (cualquiera = "en riesgo")

- [ ] Ningún siguiente paso agendado con fecha.
- [ ] Ningún contacto en 14+ días.
- [ ] Un solo contacto (single-threaded).
- [ ] El champion falló dos veces la prueba "agenda una reunión con el comprador económico".
- [ ] El comprador económico nunca fue reunido.
- [ ] Dolor no cuantificado en los números del comprador.
- [ ] Criterios de decisión no escritos por él.
- [ ] Proceso de decisión desconocido o "ya veremos".
- [ ] Proceso burocrático (legal, seguridad, compras) sin mapear en la etapa de propuesta.
- [ ] "Sí verbal" sin camino hacia la firma.
- [ ] Descuento pedido antes de la conversación de valor.
- [ ] Propuesta enviada hace más de 14 días sin respuesta.
- [ ] Competidor u opción interna nunca discutidos.
- [ ] Capacidad de entregar no confirmada internamente.

## Go / No-go

| Pregunta | Sí | No |
|---|---|---|
| ¿Hay una brecha cuantificada que el comprador declaró? | | |
| ¿Podemos arreglar su causa raíz? | | |
| ¿Hemos conocido a alguien que libera dinero? | | |
| ¿Hay un proceso de decisión con fechas? | | |
| ¿Tenemos ≥3 contactos implicados (o el negocio es tan pequeño que no lo necesita)? | | |
| ¿Podemos entregar bien si firman la semana que viene? | | |

Dos o más "No" → arregla antes de invertir más, o descalifica de forma limpia (`references/qualification.md`).

## Honestidad de etapa

| Etapa en el CRM | Debe ser verdad (criterios de etapa del SKILL.md) |
|---|---|
| Calificado | Dolor + impacto + proceso nombrado |
| Descubrimiento hecho | Scorecard: sin rojo en Dolor, Champion y Proceso |
| Propuesta | Business case aceptado por el champion; EB identificado y alcanzado |
| Negociación | Criterios cumplidos; proceso burocrático mapeado con fechas |
| Commit | Camino de firma confirmado por el EB; fecha de kickoff propuesta |

Mueve los negocios *hacia atrás* cuando la evidencia no esté. Un forecast es tan honesto como su etapa más débil.

## Motivos de cierre (sigue por separado)

Si "Sin decisión" lidera, carga `references/jolt.md` para el equipo.
